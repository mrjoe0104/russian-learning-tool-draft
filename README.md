# 러시아어 학습 도구 V3.4

- 품사 판별은 Gramota 검색 결과에 실제 표시된 러시아어 품사명을 1차 기준으로 사용합니다.
- 지원 품사 표기: `Существительное`, `Глагол`, `Прилагательное`, `Наречие`, `Местоимение`, `Союз`, `Частица`, `Междометие`, `Числительное`, `Предлог` 등.
- `Существительное` / `Местоимение` / `Числительное`: 명사 방식으로 뜻, 성, 6격 변화형을 표시합니다.
- `Глагол`: 뜻, 활용, 상, 이동동사 여부, 현재·미래·과거·명령형을 표시합니다.
- `Прилагательное`: 뜻과 6격 변화를 표시합니다.
- `Наречие` / `Союз` / `Частица` / `Междометие` / `Предлог`: 뜻과 강세가 표시된 러시아어 표제어만 표시합니다.
- 위 분류에 없는 품사도 뜻과 강세가 표시된 표제어만 표시합니다.
- 품사를 확인할 수 없으면 추측하지 않고 `판별 불가`로 표시합니다.
- 세부 변화형은 필요한 경우 Gramota 원문에서 가져오며, 품사 판별 자체는 Meta 페이지에 의존하지 않습니다.
